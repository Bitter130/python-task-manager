# Python Task Manager

## Description
This is a console-based task manager written in Python.  
The program allows users to create, view and complete tasks.

## Features
- Add tasks
- View tasks
- Mark tasks as completed
- Automatic file saving
- Error handling

## Technologies
- Python 3
- File handling
- Structured functions

## Project Goal
This project was created to improve my programming skills, especially code structure, logic and file management.
